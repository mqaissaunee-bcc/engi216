Quick start
  • Type on the home screen and press ENTER. Use 2nd (blue) and ALPHA (green) for the labels above each key.
  • Y= enter functions of X · GRAPH to plot · TRACE then ◀ ▶ to read coordinates · ▲▼ switch functions.
  • ZOOM for standard/decimal/square/trig/fit · WINDOW to set bounds.
  • 2nd then WINDOW = table setup · 2nd then GRAPH = TABLE.
  • Store values with STO▶ (e.g. 5 STO▶ A). Recall the last answer with 2nd (-) = Ans.
  • MODE switches Degree/Radian and the number format.
  • STAT → Edit lists (L1–L6), then 1-Var Stats or LinReg. 2nd x⁻¹ = MATRIX editor & operations.
  • PRGM → write and run TI-BASIC. The editor accepts your keyboard; PRGM inside the editor inserts commands (Disp, If, For, …).

Tip: pair this with the companion tutorial for worked examples in math, physics, electronics, engineering, chemistry, statistics, and finance.
