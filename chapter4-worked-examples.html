Orientation

What this session does

Chapter 2 taught you to close a vector loop and solve for position. Chapter 3 added rolling-contact and gear constraints. This chapter answers the next question every machine designer asks: once the linkage is assembled, how fast does each part move, and where does it momentarily stop? The surprise is that you do not need to know the input speed to answer most of it. Differentiate the position equations with respect to the input variable — not time — and you get the kinematic coefficients: pure geometry that captures the velocity and acceleration ratios for the whole mechanism.

Analogy — gear ratio for a shape, not just for gears

You already trust a gear ratio: “for every turn of the input, the output makes 0.4 turns,” and that is true whether you crank it by hand or spin it at 3000 rpm. A kinematic coefficient is the same promise extended to a linkage that has no gears at all. h4 = dθ4/dθ2 says “for every radian the crank advances, the rocker advances h4 radians right now.” The number changes as the linkage moves, but at any instant it is fixed by shape alone.

Why an engineer cares

The places where a coefficient hits zero are where the output reverses — the top of a windshield-wiper sweep, the end of a shaper’s cutting stroke. The places where it blows up to infinity are dead/toggle positions a clamp or landing gear is deliberately parked in. Car hoods and self-closing doors (the chapter’s programming problem) are tuned by placing these zeros and infinities on purpose. Coefficients are how you find them with algebra instead of trial and error.

The one method behind every example

Differentiate the loop with respect to the input

Every worked item below is the same three moves. Start from the solved position equations f1=0, f2=0, … (you already have these from Chapters 2–3). Pick the input variable Si — usually a crank angle θ2, sometimes a slider length. Then:

1 · First derivative

Differentiate each position equation once with respect to Si. Every unknown angle/length becomes (its coefficient)×(KC). Collect the unknown KCs on the left: J · [KCs] = b1.

2 · Second derivative

Differentiate again. Same matrix J appears — only the right-hand side changes, now carrying squared first-order KCs: J · [KCs′] = b2.

3 · Attach speed

Only now bring in the actual input rate. Velocity = (first-order KC)×Ṡi; acceleration = (first-order KC)×S̈i + (second-order KC)×Ṡi2.

The matrix J is the Jacobian of the position equations — the partial derivatives of the loop with respect to the unknown variables. It is the same Jacobian Newton’s method used to solve position in Chapter 2. That is the chapter’s quiet efficiency: build J once, reuse it for position, first-order coefficients, and second-order coefficients.

first order:   J [h, f, …]T = b1(θ, r)
second order:  J [h′, f′, …]T = b2(θ, r, h, f)

Two symbols, one idea

Stanišić writes h for a coefficient whose output is an angle and f for a coefficient whose output is a length (a slider position, or a point’s X/Y coordinate). A prime marks the second-order coefficient. Both are just slopes of an output with respect to the input:

hk = dθk/dSi  (“angle per input”)  ·   fk = drk/dSi  (“length per input”)
Notation bridge — you will see other symbols

Other books and videos call these influence coefficients or write K1, K2, or ∂θk/∂θi; complex-algebra treatments hide them inside the derivative of eiθ. They are the same object as our h and f. Map whatever symbol you meet onto “output-per-input geometric ratio.”

Problem 4.1 — what are the units of a kinematic coefficient?

A coefficient’s units depend only on what the input and output are — an angle (dimensionless, in radians) or a length. There are four combinations. This is worth internalizing once: it tells you instantly whether a coefficient should come out dimensionless, in length, or in inverse length.

Input SiOutput SkFirst-order coeff.Second-order coeff.
angle θiangle θkhk — dimensionlessh′k — dimensionless
length rilength rkfk — dimensionlessf′k — length−1
angle θilength rkfk — lengthf′k — length
length riangle θkhk — length−1h′k — length−2

Rule of thumb: each derivative with respect to a length input divides the units by one length; each derivative with respect to an angle input leaves units unchanged (radians are dimensionless). Angles-in / angles-out coefficients are always pure numbers — which is exactly why a crank-rocker’s h4 reads like a gear ratio.

Where the “length per angle” case shows up

The third row — angle in, length out — is the slider-crank engine you drive every day: crank angle in, piston position out, coefficient in millimetres per radian. Its zero is the dead-centre where the piston momentarily stops; a connecting-rod and a coefficient of zero are why an engine needs a flywheel to coast through.

Analogy — the check column is a second clock

The closed-form coefficient is your wristwatch; the finite-difference column is the wall clock you glance at to make sure your watch is right. They are computed two completely different ways — one by algebra, one by literally nudging the crank and re-solving — so when they agree to four decimals you know the algebra has no sign error hiding in it. Disagreement here is exactly how this course once caught a flipped sign that syntax-checking never would have.

Example 4.1

Inverted crank-slider — first- and second-order coefficients, then v and a of the output

Figure 4.1 is an inverted crank-slider. Crank 2 drives a block 3 that slides along link 4. With θ2 as the input and the position problem solved, (1) find the first-order coefficients, (2) set up the second-order coefficients, and (3) write the velocity and acceleration of output link 4.

crank 2 drives; block 3 slides on link 4

r₃ (slider length) and the angles change together; r₄ stays perpendicular to r₃.

Step 1 · Position equations

Loop r̄1+r̄2−r̄3−r̄4=0̄ with the slider constraint that link 4 is perpendicular to the slide:

r1 + r2cosθ2 − r3cosθ3 − r4cosθ4 = 0
r2sinθ2 − r3sinθ3 − r4sinθ4 = 0
θ4 − π/2 − θ3 = 0

Unknowns: θ3, r3, θ4. Note r3 is a length unknown — so its coefficient is an f.

Step 2 · Differentiate the X-equation

d/dθ2, treating θ3,r3,θ4 as functions of θ2 with coefficients h3, f3, h4:

r3sinθ3·h3 − cosθ3·f3 + r4sinθ4·h4 = r2sinθ2
Step 3 · Differentiate the Y-equation
−r3cosθ3·h3 − sinθ3·f3 − r4cosθ4·h4 = −r2cosθ2
Step 4 · Differentiate the constraint

θ4−π/2−θ3=0 differentiates to a clean coupling between the two angular coefficients:

−h3 + h4 = 0  →   h4 = h3
Step 5 · Assemble the system (Eq. 4.22)
⎡ r3sinθ3 −cosθ3  r4sinθ4 ⎤ ⎡h3⎤ = ⎡ r2sinθ2⎤
⎢−r3cosθ3 −sinθ3 −r4cosθ4⎥ ⎢f3⎥  ⎢−r2cosθ2⎥
⎣−1     0     1 ⎦ ⎣h4⎦  ⎣   0   ⎦

Solve this 3×3 for h3, f3, h4. Predict what the second-order system looks like before revealing.

Answer — reuse J, then attach speed

Second order: differentiate (4.22) again. The same matrix J returns; only the right side changes, picking up products of the first-order coefficients:

J·[h′3, f′3, h′4]T = b2(θ, r, h3, f3, h4)

Velocity & acceleration of output 4: with the input rate θ̇2 and rate-of-change θ̈2,

ω4 = h4·θ̇2  ·   α4 = h4·θ̈2 + h′4·θ̇22

The coefficients did all the geometry; speed only enters at the very end. build J once, use it three times

1 / 5
Analogy — the f3 row is a tape measure on a turntable

Because the slider length r3 is an unknown, its coefficient f3 measures how many inches the block slides per radian of crank. That is a tape measure laid along a spinning arm: turning the arm changes both where the tape points (the h’s) and how far out the mark sits (the f). The matrix keeps those two effects honest by solving them together.

Real inverted crank-sliders

This is the geometry of a crank-shaper’s tool ram and of many hydraulic-cylinder linkages on excavators, where a piston rod (the “slider”) rides inside a swinging arm. Engineers want ω4 and α4 of that arm to size the actuator — and this is exactly the computation that gives them.

Problem 4.3

Set up first- and second-order systems for the geared five-bar (continues 3.9)

For the mechanism of Problem 3.9 with θ2 the input: (1) write the matrix system for first-order coefficients h3, h4, f4, h5; (2) write the second-order system; (3) give ω3 and α3 in terms of the coefficients and the input rates.

two geared cranks; coupler dyad follows

Four unknowns (h3, h4, f4, h5) → a 4×4 system.

Step 1 · Start from the four position equations

Two scalar loop equations, one perpendicularity constraint, and one rolling-contact equation (3.73–3.76). All four depend on the input θ2.

Step 2 · Differentiate once → first-order system
⎡−r5sθ5 −cθ4  r4sθ4  0⎤⎡h5⎤ = ⎡r2sθ2⎤
⎢ r5cθ5 −sθ4 −r4cθ4 0⎥⎢f4⎥  ⎢−r2cθ2⎥
⎢−ρ3    1     0   ρ3⎥⎢h4⎥  ⎢   0  ⎥
⎣ 1     0  −1    0⎦⎣h3⎦  ⎣   0  ⎦

(s = sin, c = cos. Unknown order shown at right: h5, f4, h4, h3.)

Step 3 · Differentiate again → second-order system

Same coefficient matrix; only the right-hand side changes, gaining the centripetal-type terms r2cθ2, r5cθ5h52, 2f4h4sθ4, r4cθ4h42, …

J·[h′5, f′4, h′4, h′3]T = b2

Body 3 is angular, so use h3. Write the velocity and acceleration before revealing.

Identical shape to Example 4.1’s output formulas — that is the point. Once you can name the body’s coefficient, velocity and acceleration are a fill-in-the-blank.

Geared five-bars in the wild

Geared five-bar linkages appear in packaging machinery and adjustable-stroke presses, where a rolling/gear constraint removes a degree of freedom so a single motor controls a complex path. Sizing that motor needs ω3 and α3 — this setup.

Problem 4.5

A length as the input (continues 2.15)

A one-DOF mechanism with three position equations and the input taken as the slider length r4. Set up the first- and second-order coefficient systems. The twist: differentiating with respect to a length changes which coefficients are dimensionless.

slider input drives the crank

Input Si = r4 is a length, not an angle.

Step 1 · The three position equations
r1 + r3cosθ3 + r2cosθ2 = 0
r3sinθ3 + r2sinθ2 − r4 = 0
θ3 + π/2 − θ2 = 0

Unknowns: r1, θ3, r2, θ2; input r4.

Step 2 · Differentiate w.r.t. r4 → first-order
⎡−r3sθ3  cθ2 −r2sθ2⎤⎡h3⎤=⎡−1⎤
⎢ r3cθ3  sθ2   r2cθ2⎥⎢f2⎥ ⎢ 0⎥
⎣ 1     0   −1 ⎦⎣h2⎦ ⎣ 0⎥

The “−1” on the right comes from dr4/dr4 = 1. The coefficient of the length r2 is an f; the coefficients of angles are h’s.

Step 3 · Differentiate again → second-order

Same J; the right side fills with h2 and f·h products:

J·[h′3, f′2, h′2]T = [r3cθ3h32+2f2h2sθ2+r2cθ2h22; …; 0]
Step 4 · Units check

Recall the units table: with a length input, what are the units of h3 and f2?

Answer — units shift

h3 = dθ3/dr4 has units of length−1 (radians per inch); f2 = dr2/dr4 is dimensionless (length per length). Second-order h′3 is length−2 and f′2 is length−1. The algebra never changed — only the input’s units did.

1 / 4
Analogy — pushing instead of turning

Most examples turn a crank; here you push a slider. Same factory, different loading dock. The dimensionless “turns per turn” ratios become “radians per inch” because the thing you supply is now measured in inches.

Length-driven mechanisms

Hydraulic and pneumatic cylinders, lead-screw stages, and linear actuators all supply a length as the input. Their kinematic coefficients carry inverse-length units — useful when you convert a cylinder’s extension rate (in/s) into an arm’s angular velocity (rad/s).

Why no dead position here

A dead position needs the input itself to lock (|J|=0 in a way the input can’t push through). For this mechanism that would require the slider length to collapse to zero — physically impossible for a real block on a real link. So the inverted crank-slider runs freely all the way around, which is exactly why it is a favourite for shaper rams and oscillating-cylinder engines that must never stall mid-stroke.

Dead positions — where the input locks (|J| = 0)

A dead position is a configuration where the input cannot drive the mechanism — the coefficients blow up because the Jacobian is singular. Set |J| = 0 and read off the geometry. Across these four, the recurring picture is two links going collinear so a force passes straight through a pivot and makes no moment.

Example 4.3

Dead positions of the four-bar (from Example 2.1)

Take θ2 as the input on the four-bar. Find the first-order coefficients h3, h4 and the geometric condition for a dead position.

watch coupler & rocker line up

Dead when coupler r₃ and rocker r₄ are collinear.

Step 1 · Differentiate the loop
⎡−r3sinθ3  r4sinθ4⎤⎡h3⎤=⎡ r2sinθ2⎤
⎣ r3cosθ3 −r4cosθ4⎦⎣h4⎦ ⎣−r2cosθ2⎦

That 2×2 is the Jacobian J (Eq. 4.28).

Step 2 · Take the determinant
|J| = r3r4(sinθ3cosθ4 − cosθ3sinθ4) = r3r4·sin(θ3 − θ4)

(Eq. 4.29.) The coefficients are finite only while |J| ≠ 0.

Step 3 · Set |J| = 0

r3, r4 are nonzero, so the determinant vanishes only when sin(θ3−θ4)=0. Name that geometry before revealing.

Answer — coupler parallel to rocker
θ3 − θ4 = 0 or π  ⇒   r̄3 ∥ r̄4

The coupler and rocker line up (the classic toggle). There a torque on the crank cannot move the output — h3, h4 → ∞. Open the coefficient plotter and watch the curves spike at exactly these θ2.

1 / 3
Analogy — pushing a door on its hinge line

Push a door exactly along the line through its hinges and it won’t swing — your force has no lever arm. A dead position is the linkage doing that to itself: the coupler shoves the rocker straight through its own pivot, lever arm zero, no rotation.

Designed-in toggles

Vise-grips, knee-lock landing gear, and over-center latches park at this position on purpose: at the toggle a large hold-open force needs almost no input torque to maintain. The same condition you avoid in a driving linkage you exploit in a clamp.

Example 4.2

Why the inverted crank-slider has no dead position

Find the dead positions of the inverted crank-slider of Example 4.1, with θ2 the input, in terms of the position unknowns.

crank turns freely — never locks

The would-be dead position needs r₃ = 0 — force through pivot 4, no moment.

Step 1 · Determinant of the 3×3

Expanding the Example 4.1 Jacobian and using the constraint θ4−θ3=π/2 (so sin(θ3−θ4)=−1) collapses it to a strikingly simple result:

|J| = −r3
Step 2 · Set |J| = 0

|J| = −r3 = 0 requires r3 = 0 — the slider distance shrinking to nothing. Is that physically reachable for the Figure 4.1 mechanism?

Answer — the dead position exists in the math, not the machine

The block can never sit exactly on the ground pivot, so this mechanism cannot realize r3=0 — it has no dead position and the crank turns freely forever. Shrink link 2 (Figure 4.2) and the input becomes a rocker that can reach r3=0; there the contact force lies along r̄4, makes no moment about pivot 4, and the device is dead.

1 / 2
Analogy — a singularity behind glass

The dead position is real on paper but walled off by the hardware, like an asymptote a graph approaches but never touches. Recognising “the singular config can’t be assembled” is a genuine design verdict: this linkage is stall-proof.

Stall-proof by geometry

That is why oscillating-cylinder steam engines and shaper rams use this inversion — the driving member is never asked to push through a toggle, so the machine cannot jam at a bad crank angle.

Problem 4.10 (a,b)

Dead positions and transmission angle of the offset crank-slider

For the offset crank-slider with θ2 the input: (1) derive the geometric condition for dead positions; (2) identify the transmission angle.

piston reciprocates; watch μ

μ = transmission angle between rod r₃ and the slide.

Step 1 · First-order system
⎡−r3sinθ3 −1⎤⎡h3⎤=⎡ r2sinθ2⎤
⎣ r3cosθ3   0⎦⎣f4⎦ ⎣−r2cosθ2⎦

Output is a slider, so its coefficient f4 is a length-per-radian.

Step 2 · |J| and dead condition
|J| = r3cosθ3 = 0 ⇒  θ3 = ±π/2

What does θ3=±90° mean for the rod relative to the slide direction?

Answer

Dead: θ3=±π/2 means the connecting rod r̄3 is perpendicular to the slide — equivalently r̄3 ∥ r̄1. Transmission angle μ is the angle between the rod r̄3 and the slider path; at a dead position μ = 0° or 180°. Good force transmission keeps μ near 90°.

1 / 2
Analogy — pushing a swing from straight above

The transmission angle is how “sideways” your push lands. Shove a swing from directly overhead (μ near 0°) and almost nothing happens; push horizontally (μ near 90°) and it moves easily. Linkages feel the same: torque transmits best near 90°.

Engines & compressors

The offset crank-slider is the piston engine and reciprocating compressor. Designers add the offset partly to bias the transmission angle and reduce side-thrust on the piston during the power stroke.

Problem 4.9 (a)

Dead positions of a windshield-wiper mechanism

A motor drives link 2; a wiper blade is fixed to gear 5 (rolling on gear 3, with ρ3=ρ5=ρ). Using the vector loop and rolling-contact equation, find the dead positions.

blade sweeps; links 3 & 4 line up at the ends

Dead when r₃ and r₄ are in line.

Step 1 · First-order system
J·[h3, h4, h5]T = [r2sinθ2, −r2cosθ2, 0]T
J = ⎡−r3sθ3  r4sθ4  0⎤ / ⎢ r3cθ3 −r4cθ4 0⎥ / ⎣ ρ  −2ρ  ρ⎦
Step 2 · Determinant
|J| = ρ·r3r4·sin(θ4 − θ3)

Set it to zero and interpret geometrically.

Answer
sin(θ4−θ3) = 0 ⇒  r̄3 ∥ r̄4

Same toggle geometry as the plain four-bar — the gear pair changes the output ratio but not where the linkage dies. The blade reaches a dead/limit at each end of its sweep when coupler and rocker align.

1 / 2
Analogy — the wrist-flick at the end of a wave

Wave hello and your hand pauses an instant at each extreme before reversing. The wiper does the same: at the ends of the sweep the linkage hits the collinear toggle, the blade stops, then comes back — which is exactly the dwell that lets it wipe a full arc cleanly.

Every car windshield

This is a real wiper drive: a continuously rotating motor crank turned into a bounded oscillation by a four-bar plus a gear. The dead positions set the wiped arc’s edges.

Group 3 · Examples 4.4, 4.5 · Problems 4.9, 4.10 · Programming Problem 4

Limit positions & time ratio — where the output reverses (h = 0)

A limit position is where an output momentarily stops and reverses: its velocity is zero, so its first-order coefficient is zero. Set the relevant coefficient to zero — h = 0 for an angle, f = 0 for a slider — and solve. The crank angles between the two limits, in ratio, give the time ratio that measures a quick-return action.

Example 4.4

Limit positions of output link 4 (inverted crank-slider)

Find the configurations where output link 4 of the Example 4.1 inverted crank-slider reverses.

marker flashes at h₄ = 0

Limit when crank r₂ ⊥ slider r₃.

Step 1 · What reversal means

When link 4 reaches a limit it momentarily stops and reverses, so θ̇4=0 at that instant. Since ω4=h4θ̇2 and the crank keeps turning, that forces h4=0.

Step 2 · Solve (4.22) for h4 by Cramer’s rule

Expanding the numerator determinant and dividing by |J| = −r3 collapses to a clean closed form:

h4 = (r2/r3)·cos(θ3 − θ2)  (Eq. 4.30)
Step 3 · Set h4 = 0

r2, r3 ≠ 0, so the limit needs cos(θ3−θ2)=0. Picture the crank and slider vector at that instant.

Answer — crank perpendicular to slider
θ3 − θ2 = ±π/2  ⇒   r̄2 ⊥ r̄3

When the crank stands perpendicular to the slider vector, link 4 is at the end of its swing. Note this is a limit (output stops), not a dead position (input never locks — recall Example 4.2).

1 / 3
Analogy — the top of a ball’s toss

Throw a ball up: at the peak its velocity is exactly zero for an instant even though gravity (the “input”) never stops acting. A limit position is the output at the top of its toss — momentarily still, about to come back — while the crank drives on.

Limit vs dead — keep them straight

A limit position stops the output; a dead position stalls the input. A shaper’s ram reverses at limit positions every stroke (good); you never want it at a dead position (jam). The math distinguishes them cleanly: houtput=0 vs |J|=0.

Example 4.5

Limit positions of the coupler and output of the four-bar

For the four-bar of Example 4.3, find the limit positions of (a) the output link 4 and (b) the coupler link 3.

crank & coupler align at the rocker’s limit

Output limit: r₂ & r₃ collinear. Coupler limit: r₂ & r₄ collinear.

Step 1 · Output limit: h4 = 0

By Cramer on (4.28), h4 = r2sin(θ3−θ2) / [r4sin(θ3−θ4)]. Zero requires sin(θ3−θ2)=0.

θ3 = θ2 (mod π) ⇒  r̄3 ∥ r̄2
Step 2 · Coupler limit: h3 = 0

Likewise h3 = r2sin(θ4−θ2) / [r3sin(θ3−θ4)]. Zero requires sin(θ4−θ2)=0.

θ4 = θ2 (mod π) ⇒  r̄4 ∥ r̄2
Step 3 · Read it geometrically

State, in words, which links are collinear at each limit, and contrast with the dead condition from Example 4.3.

Answer

Output (4) limit: crank collinear with coupler (r̄2∥r̄3) — the familiar “crank-and-coupler in line” toggle of a crank-rocker. Coupler (3) limit: crank collinear with rocker (r̄2∥r̄4). Compare with the dead condition r̄3∥r̄4: three different pairs going collinear give three different special events. Confirm all of this on the plotter.

1 / 3
Analogy — three ways for two sticks to line up

With four links there are three pairs that can go collinear (2&3, 2&4, 3&4). Each lineup triggers a different headline event: output limit, coupler limit, or dead position. Same word — “collinear” — three different consequences.

Stroke endpoints

Output limits set the extreme angles of any oscillating output: the reach of a conveyor pusher, the open/closed angles of a linkage-driven flap. Designers solve h4=0 first because those two angles are the spec.

Problem 4.10 (c,d,e)

Coupler & slider limits and the time ratio of the offset crank-slider

Continuing the offset crank-slider: (c) limit of coupler rotation (h3=0); (d) limit of slider translation (f4=0); (e) construct the slider limits and compute the time ratio.

slider limits: rod r₃ lines up with crank r₂

Time ratio Q = (advance crank angle)/(return crank angle).

(c) Coupler limit: h3 = 0

Cramer on the offset crank-slider system gives the numerator r2cosθ2 = 0:

θ2 = ±π/2 ⇒  r̄2 ∥ r̄1 (crank along the offset)
(d) Slider limit: f4 = 0

The other Cramer numerator is r2r3sin(θ3−θ2) = 0:

sin(θ3−θ2)=0 ⇒  r̄3 ∥ r̄2 (rod in line with crank)

This is the familiar piston dead-centre: rod and crank fold in/out in line, piston momentarily stopped.

(e) Time ratio

The two slider limits occur at two crank angles. The crank turns one amount going out, the other coming back; their ratio (larger over smaller) is Q. Predict whether Q > 1.

Answer
Q = (advance angle)/(return angle) = 1.40

Q > 1 means the return stroke is faster than the advance — a built-in quick return. The offset is what makes the two crank arcs unequal; a zero-offset (in-line) slider-crank would give Q = 1 (symmetric).

1 / 3
Analogy — a rowing stroke

A rower pulls hard and slow on the drive, then slides back quick and light on the recovery. Quick-return mechanisms bake that asymmetry into the geometry: the working stroke gets more crank rotation (more time), the return less.

Shapers & planers

Metal-shaping machines use a quick-return so the cutting stroke is slow and powerful and the idle return is fast, raising throughput. Q is the headline spec for these — and it falls straight out of the two f4=0 limit angles.

Problem 4.9 (b)

Limit positions of the wiper blade

Find the mathematical condition for the limit positions of the wiper (gear 5), i.e. where the blade reverses.

blade sweeps; reverses at each end

Blade reverses where h5 = 0.

Step 1 · Reversal ⇒ h5 = 0

The blade stops at each end of its sweep, so ω5=0 and h5=0 there. Solve the 3×3 for h5 by Cramer and set the numerator to zero.

Step 2 · Expand the numerator determinant

Expanding down the input column yields a transcendental relation between the angles — not a simple “two links parallel.”

Answer
2·r3·sin(θ3−θ2) = −r4·sin(θ4−θ2)

The factor of 2 comes from the gear pair (ρ3=ρ5). Unlike the plain four-bar, the wiper’s reversal is set jointly by the linkage angles and the gear ratio — the gearing lets designers tune the sweep limits without re-cutting the linkage.

1 / 2
Analogy — a metronome with a gear

A plain four-bar wiper reverses where two links line up. Add a gear and you have a metronome whose end-points you can shift by changing the gear — the swing limits are no longer pure linkage geometry, they are geometry times a ratio.

Tuning the wiped arc

This is why geared wiper drives can hit a precise park position and a precise outer limit: the gear ratio is a second knob the designer turns to land the blade exactly at the glass edges.

Programming Problem 4

Crank-rocker: zeros, infinities, and a hood and a door

For an open four-bar (links r1=10, r2=6, r3=10, r4=8) with θ2 the input: derive h3, h4; state the geometry of h3=0, h4=0, h4=∞; connect to the auto hood (Fig. 1.14) and door (Fig. 1.15); plot the four coefficients; classify the mechanism; find the time ratio.

crank turns 360°; rocker oscillates

Shortest link (r₂=6) is the input ⇒ crank-rocker.

Step 1 · Coefficients
h3 = r2sin(θ4−θ2)/[r3sin(θ3−θ4)]
h4 = r2sin(θ3−θ2)/[r4sin(θ3−θ4)]
Step 2 · The three special geometries

h3=0: r̄4∥r̄2 (rocker in line with crank). h4=0: r̄3∥r̄2 (coupler in line with crank). h4=∞: |J|=0, i.e. r̄3∥r̄4 (coupler in line with rocker — the dead/toggle).

Step 3 · Hood & door (Figs. 1.14–1.15)

Near closed, the hood four-bar sits near h3=0 and the door near h4=∞. Why design them that way? Predict, then reveal.

Step 4 · Classify & time ratio

Grashof check on {10,6,10,8}; identify the input; from the h4=0 crossings on the plot, compute Q.

Answer

Hood (h3→0 near closed): the coupler barely rotates per unit crank motion, so the hood panel eases shut slowly and controllably instead of slamming — and a small hand force holds it. Door (h4→∞ near closed): placing the toggle near closed lets the linkage snug the door tight and resist being pushed open — a self-holding latch action.

Classification: Lmax+Lmin = 10+6 = 16 < 10+8 = 18, so Grashof; shortest link (r2=6) is the input ⇒ crank-rocker. Time ratio: with h4=0 at θ2 ≈ 45° and 260°, Q = (260−45)/[(360−260)+45] = 215/145 = 1.48.

The exact limit angles depend on how the ground link is oriented and which length is assigned to which link; the time ratio itself is orientation-independent. Drive the plotter with these lengths to see the two h4=0 crossings and the |J|=0 spikes.

1 / 4
Analogy — tuning zeros and poles

An electrical engineer places the zeros and poles of a filter to shape its response. A linkage designer does the same with h=0 (zeros, where the output rests) and |J|=0 (poles, where it locks). The hood and door are two filters tuned for opposite behaviours from the very same four-bar family.

You use these daily

Pop a car hood or let a self-closing door swing shut: you are feeling a four-bar whose coefficients were deliberately driven toward zero or infinity at the closed position. Chapter 4 is the math that put them there.

Live tool · project this

Kinematic-coefficient sweep plotter

Pick the four link lengths and the tool sweeps θ2 through a full turn, plotting all four coefficients.  dashed verticals mark dead positions (|J|=0, where the curves shoot to ∞);  dots mark limit positions (a coefficient crosses zero). This is the “plot and check” step of Programming Problem 4 — and the fastest way to see the difference between a crank-rocker (output curve stays finite) and a crank-crank (curve spikes).

h₃ h₄ h′₃ h′₄ dead (|J|=0) limit (h=0)
Analogy — a tachometer trace for shape

The plot is a tachometer for the linkage: flat-ish curves mean smooth, predictable output; tall spikes mean the mechanism is approaching a configuration where small input changes cause violent output changes. You read a four-bar’s “personality” off this chart the way you read an engine off its dyno curve.

Crank-rocker vs crank-crank at a glance

If the output coefficient h4 shoots to infinity somewhere in the sweep, the mechanism passes through a dead position and the output cannot rotate fully — it is a rocker. If every curve stays finite for all θ2, the output turns all the way around — a crank-crank (double-crank). You just classified the linkage without building it.

Group 4 · Example 4.6 · Problem 4.4

Coefficients of a point on a body → velocity & acceleration

The link coefficients (h, f) describe whole bodies. To get the velocity and acceleration of a specific point — a tool tip, a coupler point tracing a curve — locate the point with a vector, differentiate that vector using the link coefficients you already have, and the point’s X- and Y-coefficients fall out. Multiply by the input rate at the very end.

Example 4.6

Kinematic coefficients of a coupler point C (Fig. 4.7)

Point C is fixed on the coupler of a four-bar, offset from the 2–3 pin by a constant length r′3 at a constant angle φ3. Find the first- and second-order coefficients of C, then its velocity and acceleration.

C traces its coupler curve

r̄c = r̄2 + r̄′3  locates C in the fixed frame.

Step 1 · Solve the linkage first

From the loop r̄2+r̄3−r̄4−r̄1=0, get θ3, θ4 and the basic coefficients h3, h′3, h4, h′4 (Examples 4.3–4.5). C rides on body 3, so only the coupler coefficients h3, h′3 enter.

Step 2 · Locate C (Eq. 4.36)
XC = r2cosθ2 + r′3cos(θ3+φ3)
YC = r2sinθ2 + r′3sin(θ3+φ3)
Step 3 · Differentiate → first-order coefficients
fCx = −r2sinθ2 − r′3sin(θ3+φ3)·h3
fCy =   r2cosθ2 + r′3cos(θ3+φ3)·h3

These are dXC/dθ2 and dYC/dθ2 — lengths per radian.

Step 4 · Differentiate again → second-order
f′Cx = −r2cosθ2 − r′3cos(θ3+φ3)h32 − r′3sin(θ3+φ3)h′3
f′Cy = −r2sinθ2 − r′3sin(θ3+φ3)h32 + r′3cos(θ3+φ3)h′3

Predict the velocity and acceleration of C before revealing.

Answer — attach the input rate
v̄C = (fCx, fCy)·θ̇2
āC = (fCx, fCy)·θ̈2 + (f′Cx, f′Cy)·θ̇22

Speed of C is |v̄C| = θ̇2√(fCx2+fCy2). The point momentarily stops (a cusp on its coupler curve) where both fCx and fCy vanish — exactly the spiky corners you see traced on the diagram.

1 / 4
Analogy — a pen taped to a linkage

Tape a pen to the coupler and let the crank turn: the pen draws a looping “coupler curve.” The point coefficients are the pen’s velocity-shape — long where the curve is swept fast, pinched to zero at the cusps where it doubles back. Spirographs and old drafting machines are coupler curves on purpose.

Coupler curves do real work

Film-advance claws, walking-robot feet, mixer beaters, and straight-line linkages all exploit coupler-point paths. Designers need the point’s velocity and acceleration — for film registration, for foot-ground contact, for spatter — and this is the computation that delivers them.

Problem 4.4

Point A on a six-bar (continues Example 2.4)

A six-bar mechanism (six vector-loop scalar equations) with θ2 the input. (1) set up the first- and second-order coefficient systems; (2) find the coefficients of point A on one of the bodies; (3) write the velocity and acceleration of A.

four-bar drives output dyad; A is the 5-6 pin

Bigger matrix, identical recipe.

Step 1 · The coefficient systems

Six position equations → differentiate once for a 6×6 (or smaller, after using constraints) first-order system J·[KCs]=b1; differentiate again for the second-order system with the same J and a new b2. The matrix is bigger; nothing else is new.

Step 2 · Coefficients of point A

Locate A with a fixed-frame vector r̄A built from the loop vectors and a constant offset on its body. Differentiate, substituting the body’s h and h′ just solved:

fAx = ∂XA/∂θ2,   fAy = ∂YA/∂θ2  (and primes for 2nd order)
Step 3 · Velocity & acceleration of A

Same final move as Example 4.6 — write them before revealing.

Answer
v̄A = (fAx, fAy)·θ̇2 ·  āA = (fAx, fAy)·θ̈2 + (f′Ax, f′Ay)·θ̇22

The takeaway across Group 4: once you have a body’s h and h′, any point on it is two more derivatives and a dot with the input rate. The mechanism’s size never changes the recipe.

1 / 3
Analogy — scaling a recipe

Going from a four-bar to a six-bar is like doubling a recipe: more of the same ingredients and a bigger bowl (matrix), but the steps are unchanged. If you can cook Example 4.6, you can cook this.

Six-bars buy motion you can’t get from four

Stephenson and Watt six-bars give dwells, exact straight lines, and figure-eight paths a four-bar can’t — used in packaging indexers and rehabilitation exoskeletons. Their point velocities and accelerations come from this exact, scalable procedure.

Group 5 · Example 4.7 · Problems 4.6, 4.7, 4.8

Geartrain coefficients — speed ratio & gear ratio

Gear and rolling constraints are linear in the angles, so differentiating them is almost trivial — the coefficient matrix is just rolling radii (or tooth numbers). The output coefficient is the speed ratio ns, and the gear ratio is its reciprocal R = 1/ns. One bonus: because the ratio is constant, the second-order coefficients are zero, so a constant input speed gives zero output acceleration.

Example 4.7

Planetary train (from Example 3.8) — coefficients, speed ratio, gear ratio

A planetary train with gear 5 fixed and θ6 the input (arm). Find the first-order coefficient of output gear 2, the speed ratio ns and gear ratio R, and the second-order coefficients.

arm 6 drives; planet rolls; output 2 turns

Gear 5 fixed · input arm θ6 · output gear 2.

Step 1 · Differentiate the rolling-contact equations

The homogeneous rolling equations (4.47–4.48), differentiated w.r.t. θ6 (with gear 5 fixed), give two linear relations:

h34 + (ρ2/ρ3)h2 = 1 + ρ2/ρ3  ·   h34 = 1 + ρ5/ρ4
Step 2 · Matrix form (Eq. 4.51)
⎡1  ρ2/ρ3⎤⎡h34⎤=⎡1+ρ2/ρ3⎤
⎣1   0  ⎦⎣h2 ⎦ ⎣1+ρ5/ρ4⎦
Step 3 · Solve for the output coefficient h2

Cramer’s rule. This h2 = dθ2/dθ6 is exactly the speed ratio. Predict its form, then reveal.

Answer
ns = h2 = 1 − ρ3ρ5/(ρ2ρ4)  (Eq. 4.52)

Gear ratio R = 1/ns. Second order: the same matrix with a zero right-hand side gives h′2 = h′34 = 0 — the ratio never changes with position, so a steady arm speed means zero output acceleration. That zero is the signature of a gear train versus a linkage.

1 / 3
Analogy — the coefficient method swallows Chapter 3

In Chapter 3 you found gear ratios with the “formula method” bookkeeping. Here the very same answer drops out of one differentiation — the speed ratio is just the output’s kinematic coefficient. One method now covers linkages and gear trains.

Why h′ = 0 matters

Constant second-order coefficients are why a gearbox at steady rpm produces no acceleration ripple, while a linkage at steady input speed still accelerates its output (the h′·ω2 term). It is the kinematic reason gears feel smooth and linkages feel “lumpy.”

Problem 4.6

Planetary speed ratio with numbers (continues 3.13)

Input arm 1 at θ̇1=3000 rpm and θ̈1=80 rev/s². Find ns=h5, then ω5 and α5.

gears spin; ratio is constant

Second order vanishes ⇒ α is just h·θ̈.

Step 1 · First-order system
⎡ρ3  0 ⎤⎡h34⎤=⎡ρ3−ρ2⎤
⎣ρ4 −ρ5⎦⎣h5 ⎦ ⎣ρ4−ρ5⎦
Step 2 · Speed ratio
ns = h5 = 1 − ρ4ρ2/(ρ3ρ5) = 1 − N4N2/(N3N5) = 0.12

Agrees with the gear ratio from Problem 3.13: ns = 1/R.

Step 3 · Output ω and α

The second-order system has a zero RHS, so h′5=0. Compute ω5, α5.

Answer
ω5 = h5θ̇1 = 0.12(3000) = 360 rpm
α5 = h5θ̈1 + h′5θ̇12 = 0.12(80) + 0 = 9.6 rev/s²

Because h′5=0, the ω2 term drops — output acceleration tracks input acceleration through a constant factor.

1 / 3
Analogy — a reliable exchange rate

ns=0.12 is a fixed exchange rate: 3000 input “dollars” always buy 360 output “euros,” and any change in the input rate converts at the same 0.12. No surprises — that is what h′=0 buys you.

Planetary reducers

Planetary gearsets in automatic transmissions, e-axle reducers, and robot joints are picked for exactly this ns. Here it falls out of one Cramer’s-rule solve instead of a tabulated train-value formula.

Problem 4.7

Set up a four-rolling-contact transmission (continues 3.15)

Input 6, output 9. (1) Write the first-order coefficient system in matrix form; (2) express ns in the coefficients; (3) write ω89, α89.

four meshing members turn together

Four rolling contacts → 4×4 system.

Step 1 · Differentiate four rolling equations

Each rolling/gear pair gives one linear equation in the unknown coefficients h27, h34, h5, h89:

⎡ 0   ρ3  0  ρ9 ⎤⎡h27⎤ ⎡ 0 ⎤
⎢ ρ7  0   0  ρ8 ⎥⎢h34⎥=⎢ 0 ⎥
⎢ρ5−ρ4 ρ4 −ρ5 0 ⎥⎢h5 ⎥ ⎢ 0 ⎥
⎣−(ρ6+ρ5) 0 ρ5  0 ⎦⎣h89⎦ ⎣−ρ6⎦
Step 2 · Speed ratio & output kinematics

Output is body 89, so ns = h89. Write ω and α (remember h′=0 for gears).

Answer
ns = h89 ·  ω89 = h89ω6 ·  α89 = h89α6

No second-order term survives — pure gearing. Solving the 4×4 by Cramer gives a closed-form ratio in the radii; the setup is the deliverable here.

1 / 2
Analogy — one equation per handshake

Each rolling contact is a handshake between two gears that must agree on surface speed. Every handshake is one row of the matrix. Count the handshakes, write the rows, solve — the train’s size is just the number of handshakes.

Compound transmissions

Multi-stage industrial gearboxes and wind-turbine drivetrains are exactly this: several rolling/gear contacts stacked. The matrix scales by one row per stage, and the output coefficient is the overall ratio.

Problem 4.8

Compound output 9&3, with numbers (continues 3.16)

Input 2 at a constant 2000 rpm; output is the compound element 9&3. Find h93 by Cramer’s rule, the speed ratio, and the output ω and α.

idler 8 reverses sense, not ratio

A column of ρ8 terms cancels top and bottom.

Step 1 · Cramer for h93

Solve the 4×4 system for the output coefficient. Expanding numerator and denominator down the ρ8 column cancels ρ8 entirely:

h93 = N2N4N6 / [−N3N5N7 + N4N6N7 + N2N4N6]
Step 2 · Plug in the tooth numbers
h93 = (38)(22)(92) / [−(46)(10)(55)+(22)(92)(55)+(38)(22)(92)] = 0.472

So ns = h93 = 0.472. Compute the output speed and acceleration.

Answer
ω39 = nsω2 = 0.472(2000) = 944 rpm (same sense as input)
α39 = h93·θ̈2 + 0 = 0 (input is constant)

And ns = 1/R, matching the gear ratio from Problem 3.16 — the coefficient method and the train-value formula land on the same number.

1 / 2
Analogy — a term that cancels is a part that doesn’t matter

The ρ8 column cancelling top and bottom is the algebra telling you idler 8 changes direction, not ratio — the classic “idler gear” result, here proven by a determinant rather than asserted.

Positive ratio = same direction

ns > 0 means output 9&3 spins the same way as input 2 — useful when a design must preserve rotation sense through a reduction, as in many spindle and conveyor drives.

Self-Check

Quick check — the distinctions that matter

Pick an answer; the explanation appears. These target the traps, not the arithmetic.

1. A four-bar’s output rocker momentarily stops and reverses. Which condition holds at that instant?

The output stopping means ω4=0 while the crank still turns, so h4=0 — a limit position. |J|=0 is a dead position (the input locks); θ̇2 never goes to zero here.

2. Going from the first-order to the second-order coefficient system, what changes?

The Jacobian J is reused for position, first-order, and second-order. Only the right-hand side gains the products of first-order coefficients (the h² and f·h terms).

3. For an angle-input, length-output coefficient (e.g. a slider position per crank radian), the first-order coefficient has units of…

d(length)/d(angle) = length per radian = length (radians are dimensionless). That is the piston-per-crank case.

4. In the inverted crank-slider of Figure 4.1, why does it have no dead position?

The determinant reduces to −r3. Setting it to zero needs the slider distance to vanish — physically impossible for a real block, so the crank turns freely forever.

5. For a pure gear train at constant input speed, the output angular acceleration is…

Gear ratios are constant, so h′=0. Then αout = h·θ̈ + h′·θ̇² = h·θ̈; with constant input (θ̈=0) the output acceleration is zero — unlike a linkage, whose h′·ω² term survives.

6. A crank-rocker has its two output limits at θ2=45° and 260°. Its time ratio is…

Time ratio is the larger crank arc over the smaller: advance 215°, return 145°, Q≈1.48. A quick-return: the return stroke is faster.

7. The dead position of a four-bar occurs when which pair of links is collinear?

|J| = r3r4sin(θ3−θ4) = 0 means coupler ∥ rocker. (Crank∥coupler and crank∥rocker are the limit conditions for the output and coupler respectively.)

The method

First order: J·[KCs] = b1(θ,r). Second order: J·[KCs′] = b2(θ,r,KCs) — same J. Velocity: ωk=hkθ̇i, point v=(fx,fy)θ̇i. Acceleration: αk=hkθ̈i+h′kθ̇i2, point a=(fx,fy)θ̈i+(f′x,f′y)θ̇i2.

Four-bar coefficients

J = [[−r3sθ3, r4sθ4],[r3cθ3, −r4cθ4]]; b1=[r2sθ2; −r2cθ2].
h3=r2sin(θ4−θ2)/[r3sin(θ3−θ4)]
h4=r2sin(θ3−θ2)/[r4sin(θ3−θ4)] (r4, not r3!)

Dead & limit (four-bar)

Dead |J|=r3r4sin(θ3−θ4)=0 → r3∥r4.
Output limit h4=0 → r3∥r2.
Coupler limit h3=0 → r4∥r2.

Time ratio

Q = (advance crank arc)/(return crank arc), larger over smaller. Q=1 symmetric; Q>1 quick-return. Limits at the two houtput=0 crank angles.

Inverted crank-slider

|J|=−r3 → no realizable dead position. Output limit h4=(r2/r3)cos(θ3−θ2)=0 → r2⊥r3.

Geartrains

Speed ratio ns = houtput; gear ratio R = 1/ns. Coefficient matrix = rolling radii (or tooth numbers). h′ = 0 (constant ratio).

Units of KCs

θ→θ: h, h′ dimensionless. r→r: f dimensionless, f′ length−1. θ→r: f length, f′ length. r→θ: h length−1, h′ length−2.

Glossary

Terms used in this session

Kinematic coefficient — the derivative of an output variable with respect to the input variable (not time). Pure geometry; captures velocity/acceleration ratios at every speed.
First-order coefficient (h, f) — d(output)/d(input). h for an angular output, f for a length output (slider or a point coordinate).
Second-order coefficient (h′, f′) — d²(output)/d(input)². Supplies the ω² term in acceleration; zero for gear trains.
Jacobian J — the matrix of partial derivatives of the position equations w.r.t. the unknown variables. Same J solves position (Newton), first-order, and second-order coefficients.
Dead position — a configuration where the input cannot drive the mechanism: |J|=0, coefficients → ∞. Also called a toggle or dead point.
Limit position — a configuration where an output momentarily stops and reverses: its first-order coefficient is zero (h=0 or f=0).
Toggle / dead point — the four-bar dead position where coupler and rocker are collinear; exploited by clamps and over-center latches.
Transmission angle (μ) — the angle between coupler and output near 90° transmits force well; 0°/180° marks a dead position.
Time ratio (Q) — ratio of crank rotation during the working stroke to the return stroke (larger over smaller). Measures quick-return action; Q=1 is symmetric.
Speed ratio (ns) — output angular velocity per input; for a gear train it equals the output’s kinematic coefficient.
Gear ratio (R) — reciprocal of the speed ratio, R = 1/ns.
Influence coefficient — another name for a kinematic coefficient, common in other textbooks and complex-algebra treatments.
Coupler curve — the path traced by a point fixed on a coupler as the mechanism moves; its velocity follows the point’s f-coefficients.
Crank-rocker — a Grashof four-bar in which the shortest link (the input) rotates fully while the output oscillates between two limit positions.
Branch (open/crossed) — the two position solutions of a closed loop; the solver and plotter let you switch between them.
Quick-return — a mechanism whose return stroke takes less input rotation than its working stroke (Q>1); used in shapers and planers.

No terms match that filter.
